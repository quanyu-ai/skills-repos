# 可选导航模式

导航结构与视觉语言独立：任一模式都可映射项目既有品牌、颜色和组件。它们不是全局默认、菜单权限系统或安装器。已有导航继续沿项目确认基线，只有本批授权改变时才迁移。

| 模式 | 适用条件 | 结构 |
| --- | --- | --- |
| [分组侧栏与抽屉 / Grouped Drawer](grouped-drawer.md) | 单一工作环境，功能可按任务分组 | 分组 → 入口；宽屏侧栏、窄屏抽屉 |
| [职责空间 / Space–Domain Workspace](space-domain-workspace.md) | 有真实稳定的职责空间和较大功能量 | 空间 → 域 → 功能；域内导航与跨空间查找 |

不要按菜单数量硬选模式：空间是工作上下文，域是空间内的业务分组，菜单项是功能入口，不是把任意三级树改名。普通小系统不为“扩展性”提前造空间；大型系统不为扁平美观抹掉职责边界。

[合成可运行示例](../../assets/navigation-pattern-demo/index.html)可比较两模式、切换示例空间、查看完整结果路径；无API、授权或持久化。示例视觉沿浅色空间，功能数据全为虚构，不能直接当产品菜单。各模式的[效果图](../../assets/navigation-pattern-demo/preview-space-domain.png)只说明布局，不证明真实业务和辅助技术全覆盖。

共同接入条件：从项目当前可见目录取得功能；路由、当前项、面包屑、搜索、常用引用同一标识；导航展示不决定业务授权。菜单、品牌首页及无参数默认落点共同遵守业务归属。首次使用按本次影响验证宽/窄、长名、当前项、加载/空/失败、键盘与返回；只复用版本和状态仍适用的证据。
