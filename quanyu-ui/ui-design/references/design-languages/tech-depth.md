# 科技纵深 / Tech Depth

## 意图与适用

通过深色表面、边缘光和受控材质建立聚焦感。适合技术运营、任务执行、分析或沉浸工作面；是否适合长时间表单办理需要用真实内容判断，不因为“科技”主题而新增监控数据或指标。

## 设计语法

- 色彩：深蓝或中性深色环境，正文表面比环境略亮；青蓝/蓝紫作为少量焦点。起步示意：canvas #0a1020、surface #111c31、ink #eaf1ff、muted #a1b2cc、accent #7bdcff。状态语义仍来自项目。
- 构图：环境层、工作表面、临时浮层有明确层次。任务与结果是焦点，网格和光晕留在外围；不能让导航或装饰比内容更醒目。
- 材质：统一光源方向，用顶边高光、近阴影和扩散阴影表达深度；每种表面有固定角色。正文不叠复杂反射背景，不能只靠黑色阴影区分深色层次。
- 排版：正文与辅助标签分别保持足够对比；小字不能用暗蓝代替可读的次级色。精确ID可用项目等宽角色，但整页技术标识不能压过业务名称。
- 密度：表格用稳定行列、清晰选中与焦点；不能把每行都做成发光悬浮卡。复杂表单降低装饰，维持字段、校验和操作区边界。
- 动效：hover与反馈可以轻量变化，默认无循环光效、自动漂浮或粒子层；静态及减少动态效果时仍能读懂状态。

## 复杂场景与观察

检查不同深色表面的分离、正文/失败提示/禁用控件的辨识、浮层和键盘焦点。成功、运行、未知、失败不因光效变成同一种“在线绿色”；视觉亮度不得推断真实运行事实。窄屏要实看发光边缘是否裁切和长版本是否可读。昂贵模糊或动画有实际需求时再做性能验证，不根据静态图声称流畅。

正例：结果入口有有限蓝色强调，失败步骤仍清楚显示原错误和原任务续接条件。反例：给失败状态加绿色光圈制造完成感，或为了截图填入未经观测的任务数。
