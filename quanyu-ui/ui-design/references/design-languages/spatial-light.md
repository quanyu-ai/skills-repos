# 浅色空间 / Spatial Light

## 意图与适用

以柔和环境、悬浮导航和稳定的浅色正文表面形成精致、轻盈的工作空间。适合需要辨识度的综合工作台与内容详情；高密度处理、长表单及异常反馈必须另外验证。它是可选语言，不是插件的全局默认。

## 设计语法

- 色彩：珍珠白工作面、低饱和冷色环境、少量明确的彩色焦点。起步示意：canvas #eef1fa、surface #ffffff、ink #29334d、muted #69758c、accent #6263c8。背景光感不能成为业务状态通道。
- 构图：导航及辅助操作可以有悬浮感；内容主体保持连续、稳定。环境层衬托工作面，不能把表单拆成大量独立玻璃小岛。
- 材质：通透效果集中于导航、工具栏和辅助层；密集表格、正文、字段编辑及错误提示用实色或接近实色底。实现不支持透明/模糊时用清晰实色替代，语义不变。
- 排版：柔和不等于低对比。正文、字段标签、校验和长版本按项目可读角色呈现；先压装饰和重复说明，再考虑密度，不能靠小灰字支撑复杂页面。
- 圆角与深度：同级表面统一尺度、阴影方向一致；大圆角仅用于容器，不机械套到每个表格单元、输入框和状态。分组可用间距而非更多卡片。
- 反馈：强调色只用于少量主动作/当前项；错误、未知、无权限与忙碌遵循原状态含义，不能为了柔和改成淡到难辨的提示。

## 复杂场景与观察

扩展前至少找到本次影响的真实代表场景：密集列表检查列宽、选中、批量操作与滚动；复杂表单检查必填、字段错误、焦点和提交反馈；异常状态检查失败、未知、受限与返回路径。按任务选样本，不造真实业务数据。没有覆盖的场景记未验，不把一个详情成功态称作全平台适配。

实看不同背景、桌面/窄屏、长内容及浮层，确认透明区域没有降低可读性，固定/悬浮区域不遮挡内容；静态图与浏览器固定背景捕获有差异时明确说明。提供正常/紧凑密度适配，不因此引入另一套品牌与业务组件。

正例：柔和彩色背景托住实色字段区，原件和错误引用仍清晰可读。反例：每个字段都透明透底、表格文字落在复杂渐变上，或用巨大留白牺牲日常处理效率。
