# 工作区结构与CSS接入

适用于对象办理、任务运营、成果阅读等工作型系统。结构与材质独立：光场空间、电影柔光、银蓝精工均可搭配相同布局；品牌和目标任务决定最终选择。下列像素为[示例CSS](../../assets/design-language-demo/languages.css)的起步值，不是所有项目的固定门槛。

## 1. 选择布局，而不是统一卡片模板

| 任务 | 推荐结构 | 不适用时 |
| --- | --- | --- |
| 频繁处理很多记录 | 筛选+全宽连续列表；短预览可在受支持的侧面板中承载 | 长流程/大量附件转独立对象页；不强制三栏 |
| 单对象办理/跟踪 | 对象头+事实摘要；主工作面与较窄上下文栏 | 工作宽度不足时上下堆叠；无辅助内容时不留空栏 |
| 长文/成果阅读 | 连续阅读面+可选章节目录；来源按需展开 | 不能把必须立即看到的风险移走 |
| 复杂表单 | 连续章节表单+错误摘要；长流程使用项目已有步骤机制 | 不为视觉升级新增步骤或改变提交条件 |

## 2. 导航与对象头

- 全局导航按用户任务分组，常用工作与系统管理层级区分；分组依据项目真实目录，不能从本例照搬业务分区。深层入口保留可发现路径及权限语义，折叠不是删功能。业务归属还需同时核对正式菜单、品牌回首页和无参数默认路由；仅移走菜单、仍默认进入业务场景，会继续混淆平台与业务。独立联调/演示场景用明确的开发直达入口，不因已有页面和数据自动成为正式产品模块。
- 宽屏导航可从224–240px起步；内容需宽时可采用项目支持的折叠机制。不要将窄屏全部入口机械塞入一条很长的横向菜单。窄屏用有可访问名称的菜单入口，展开/关闭后保留当前项和焦点；原有模态契约继续有效。
- 页头先回答“在哪、正在处理哪个对象”，再放主要动作。位置导航、对象操作、视图筛选分工固定；不要让用户在每页重新寻找操作。
- 设计对比器、调试和评审控件属于设计环境，普通产品不继承。帮助/说明不逐项占一整块；必要限制仍就近可见。

## 3. 状态摘要与任务/结果层级

对象头下用一条可换行的事实摘要呈现当前阶段、责任方、下一步；不同对象的状态必须有名称，不能混成一个总体“成功”。缺真实值时显示准确缺口，不造指标。

已有成果与当前办理状态分别核对：只因结果对象存在就把成果前置，可能掩盖后续失败、执行中或未知尝试。当前异常、阻断和允许核对/恢复动作优先；正常完成且以阅读为目的时再突出成果。保持信息的实际DOM顺序与视觉顺序一致。

主工作面由当前任务决定：处理中优先当前步骤与阻断；已有结果且用户来阅读时优先成果入口/正文；失败或未知优先原尝试、核对与允许的恢复。已完成历史和技术追踪可逐层展开，当前异常与需要采取的行动不可藏入折叠。

桌面主/辅从 `minmax(0,1fr) minmax(16rem,20rem)` 起步。上下文栏承载来源、固定版本、责任、关联对象；不要与主区重复整套状态和主动作。批处理表格不套此分栏，优先给比较列足够宽度。

## 4. 窄屏与连续性

当主辅均不能保持可读宽度时改为一列；本例在960px切换，不把该断点当设备事实。顺序保持：对象→关键异常/当前事实与动作→主工作→来源/历史。不要用CSS视觉重排造成键盘/阅读顺序与画面相反。

长版本 `overflow-wrap:anywhere`；grid/flex子项 `min-width:0`；跨行比较表格保留区域横滚而非整页横滚。触控控件示例44px，紧凑桌面允许项目既有密度。固定工具条应计入自身高度、缩放和安全区，不能遮住末项或错误焦点；不需要固定时沿文档流。

## 5. CSS规范及组件映射

- 以一个局部根选择器承载语言，Token角色分为 canvas / environment-ink / surface / ink / muted / accent / semantic-state / line / depth / radius。嵌套浅表面明确文字角色，暗环境不继承正文深字。已有Token的项目做映射，不创建第二套竞争主题。
- 组件层持有布局与状态；语言层只提供材质/角色值。相邻模块同级表面遵循同一尺度，先用间距分组，再考虑卡片嵌套。
- 参考间距4/8/12/16/24/32；普通正文14–16px、章节16–18px、页标题28–34px；实际中英文字体与密度由项目验证。不要通过小字低对比隐藏必读信息。
- 选择/错误/焦点分别建状态。用 `:focus-visible` 轮廓、文本/图标与 aria 属性协同表达。错误规则要能覆盖主题控件边框；无颜色也能判断状态。
- 示例仅环境使用有限静态渐变，正文、表格和字段实色。模糊局限辅助层；`@supports`、减少透明度、减少动态效果提供清晰降级；不引入shader、动画库或远程字体依赖。
- 主题选择、筛选与当前状态若保留在URL，修改参数用 `URLSearchParams.set`，不要追加同名参数；按项目返回/草稿契约处理，不因示例承诺持久化。布局上下文若需保留，应覆盖详情→结果→字段定位/原件→返回的完整只读链；定位参数与视图参数分别保留。读者页可沿用自身布局，不必为保留返回上下文把所有页面强行套同一主题。

## 6. 观察标准

在实际字体下检查宽/窄视口、长内容、列表/表单/异常、焦点、浮层及返回上下文。WCAG 2.2 AA文字/非文字对比度按项目适用要求核验，参考[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)和[非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)；CSS色值存在不能证明叠色后的实际对比。示例不声称全场景可访问性认证。

[独立可运行示例](../../assets/design-language-demo/index.html)包含三语言同内容、详情/列表/表单/异常与窄屏导航；均为合成展示，无API、存储或业务写入。可直接用浏览器打开，或以项目已有静态服务器托管。浏览器截图示例见该目录的 preview-*.png；不同字体/缩放下效果可能不同。移植时只复用结构关系与CSS，不复制合成字段当产品需求。
