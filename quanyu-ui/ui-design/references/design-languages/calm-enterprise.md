# 沉稳商务 / Calm Enterprise

## 意图与适用

让用户快速扫描对象、状态、下一动作和数据关系。适合办理型后台、目录、权限配置、长表格和多步骤表单；若用户要求品牌展示或沉浸效果，先说明其视觉表达较克制，不把它当所有项目的默认。

## 设计语法

- 色彩：低饱和中性背景、实色主工作面和单一品牌强调。起步示意：canvas #f7f8fa、surface #ffffff、ink #20232d、muted #697180、accent #5754c7；实际映射项目Token。
- 构图：位置导航、页面身份、工作页签和业务动作分层；正文连续，辅助版本/来源退居次级。相关字段用分组和间距，不每字段一张卡。
- 表面：浅边界、轻阴影和有限圆角即可区分层级；弹层高于内容，普通区块不能都像弹窗。组件高度、圆角及间距沿项目尺度。
- 排版：标题/章节/标签/值/辅助引用有不同角色。名称和值易读，ID与版本可展开或折行；不要为露出更多行把关键文字缩成脚注。
- 密度：用稳定列宽、紧凑工具栏、列对齐和合并重复说明提高效率，保留触达和焦点空间。常规详情与紧凑表格可同属一语言。
- 反馈：状态文字是主通道，颜色辅助；主要动作突出，其余操作降低权重但仍易发现。焦点、禁用与忙碌分别呈现。

## 复杂场景与观察

密集列表要能定位当前行、筛选范围和主要操作；复杂表单要看得出分组、必填、错误位置及草稿状态；失败/未知/无权限要说明当前事实和合法下一步，不能统一灰卡。按任务验证桌面/窄屏、长内容、焦点和返回上下文。

正例：在同一工作面使用章节与精确版本辅助行区分主次，筛选后仍识别当前范围。反例：所有卡同等粗边框、所有文本同等加粗，或去掉来源与版本让界面显得干净。

## 参考边界

可参考[Linear的信息主次与导航处理](https://linear.app/now/behind-the-latest-design-refresh)和[IBM Carbon导航结构](https://www.carbondesignsystem.com/building-blocks/core/components/ui-shell-left-panel/specifications)。借鉴组织关系，不表示导入它们的组件、字号、商标或业务动作。已有项目风格优先；验证的是当前任务的真实呈现。
