# 视觉组织：判断方法与正反例

按本次影响选择条目，不是每次完整重做。示例都是关系/结构示意；项目既有组件接口、尺度与品牌优先。

## 1. 文字角色决定主副关系

**问题：** 入口名称、路径、字段标签和分组标题全用同一字号/字重；副文字继承外层按钮粗体。结果是主副两行像两条同级事项。

**正确做法：** 先区分页面标题、区块标题、入口/记录名称、字段标签、字段值、说明和状态。为相关主副文字成套选字号、字重、行高、颜色与行距；必要正文和错误不应为制造层级而难读。字段标签和值不一定靠字号差区分；不同角色也不应机械套同一比例。

**正例：** 入口名称用项目入口角色，所属路径用次要元数据角色；父控件按多行内容自然增长并保留触达区域。详情分组标题结合分组间距/分隔，字段值维持正文可读性。

**反例：** 全部放大加粗；副文只调浅颜色而继承粗体；把两行内容塞进单行控件定高；临时引入另一字体让标题显得“高级”。

**观察：** 检查实际字体、计算样式与换行。短名、长路径及窄屏下仍能一眼区分主名称和补充信息，文字不触碰分隔线。浏览器字体回退与声明的 font-family 不等同。

## 2. 首屏与连续工作面

**问题：** 帮助、口径、刷新和统计各占一整块，用户看不到实际结果或办理动作；所有卡片等大等重。

**正例：** 标题识别任务；常用条件与结果保持连续；来源/口径在其影响的区域说明；让主要工作面明显，辅助信息按需展开。项目采用标题帮助按钮时正确复用，不再复制一段说明。

**反例：** 为装饰加 KPI、虚构综合分；把所有说明都移进帮助而藏掉必须立即知道的风险或状态；为让首屏露出结果缩小到不可读。

**观察：** 目标视口第一工作屏能识别对象、当前状态和下一步。长表单或沉浸内容可以有不同节奏，不套统一的“首屏必须 N 卡/一行结果”数字。说明文字去留按任务决定，不把某项目禁副标题扩为通用禁令。

## 3. 列表与宽度按语义分配

**问题：** 姓名空列吸收大量空间，长机构/地点受挤；只有类别与数量的短列表沿用大表格最小宽度而出现横滚。

**正确做法：** 根据字段角色、代表性长值与持续扫描任务确定稳定列策略。标识、主状态和动作优先；次要字段可按目标端收敛。短键值/分类计数可用项目已有摘要或紧凑列表，跨行比较才优先表格。

**正例：** 选择受支持的语义列宽/伸缩列，长机构有合理读取空间及完整值途径；窄屏可用保留标识、状态与动作的记录结构。数字对齐规则随比较任务选择。

**反例：** 只按当前第一页字符长度动态改宽；两列短摘要强制大表格；无限压缩长值；用 tooltip 存在证明扫描效率合格；所有记录都拆成孤立大卡。

**观察：** 切换加载、空态、翻页和长值后布局稳定；如需横滚，应局限于明确的内容区域，不能把当前任务的关键状态永久放在视野之外。截图要包含表格所在实际容器，单独表格渲染不能代整页判定。

## 4. 编辑与详情的发现和返回

**问题：** 点击后编辑面出现于长列表底部；关闭详情后列表条件或焦点丢失。

**正例：** 依任务复杂度选原有内联、弹窗、侧面板或独立页；打开立即可察觉且标明原对象。按实际组件契约组织头部、正文、动作区和滚动，既能读到末项，又能找到取消与主动作。

**反例：** 一律弹窗；通过去掉模态背景约束允许操作被遮挡列表；把固定操作栏套进滚动正文；关闭与 Escape 采用不同草稿语义。

**观察：** 从列表后部打开，走到长内容底部，再关闭或取消，仍回正确对象/条件及可见控件。注意打开/取消可能有真实副作用，先确定本次允许操作的路径，不为视觉截图制造业务记录。

## 5. 表面、深度与光学精度

**问题：** 页面全是等权白卡、同粗边框；或反过来给每卡渐变/强阴影，层级仍不清。

**正确做法：** 让背景、主工作面、辅助分组和临时浮层各有可辨关系。使用项目既有表面/边线/阴影角色，优先解决间距、边缘和基准线。需要时增强浮层与背景分离，而非所有东西同样凸起。扁平风格本身不构成缺陷。

**正例：** 连续表单保持一个工作面，相关字段用节奏分组；临时菜单在真实容器内可辨且不被裁切；同级卡标题基线一致，说明长短不挤压相邻主内容。圆角、图标、字体、数字和分隔线遵循同一套项目角色。

**反例：** 每字段一张悬浮卡；重复卡片嵌套；靠玻璃/光晕弥补信息无主次；用固定内容高度掩盖可变说明导致的对齐差异。

**观察：** 在实际主题、内容和目标视口看整体主次及局部对齐，再开浮层确认前后关系、边缘、遮挡。不能把固定阴影数值、某个强调面积比例作为所有产品门槛。

## 6. 动效与状态

**正例：** 项目允许时，用短暂状态过渡解释展开、切换、选择或反馈位置；有明确触发和结束，遵守已有减少动态效果策略。即使动画关闭，结果和操作关系仍明确。

**反例：** 持续闪动的指标、无意义入场队列、通过动画制造尚未成功的完成感；为了美观抹去来源失败、结果未知或只读状态。

**观察：** 实际点击而不是只看一张静态图。操作反馈对应真实/合成来源中已确认的结果；纯视觉模拟不证明后端或持久化。已有产品不需要动效时，不为“升级视觉”强加动效系统。
