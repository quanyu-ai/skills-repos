# 从视觉方案到实际产品的质量控制

用于已选定视觉方向、真实产品落地或共享基础推广。不是新的审批流程；已有授权内继续整改，项目既有独立复核负责判断。

## 绑定确认设计与实际消费版本

沿项目现有入口确认当前采用的设计／组件约束、实际加载的技能来源与运行候选。发现工作树仍消费旧技能时，从唯一有效来源读取适用内容；只有来源变化影响当前任务时才刷新原准备结果；不能以源规则已合并或文件已保存代替实际加载，也不直接改插件缓存。路径、版本和本批采用事实留原交付记录，不搬成跨项目固定路径。

## 先判用户结果，再找退化原因

从用户要判断或完成的任务检查实际消费者。总览须有明确范围、真实状态与关注对象，并能到同条件名单、原依据后返回；办理须在决定前给足正文和条件；成果阅读须可连续读到实际内容。只有入口、字段映射或漂亮样例而缺少这些结果，应继续修产品，不以“视觉已过、业务另验”绕开。统计单位、期间、授权子集、分母与观察时点要能解释，同源/跨源关系不能由布局暗示成同一快照。



- 局部样例只有理想内容，而真实页含长名称、多状态和表单：先把真实内容放进同一可操作布局；不能删资料、伪造摘要或以样例漂亮证明真实产品可承载。
- 色板、圆角已复制，比例和信息主次未落实：从共享外壳、字体层级、表面角色及基础控件建立单一维护源，再验证业务组合。别只堆页面专用覆盖；也不强制某个文件数量或框架。
- 密度靠缩小字号，或精修反而增加无效留白：用同内容、视口比较可完成任务的信息量，先合并重复元数据、调整列和展开顺序；阅读和触达不能被首屏条数取代。
- 设计事后反向追随实现：保留原目标，明确实际偏差及其必要性；不能由实施者把未解决的问题改称“有意差异”而免验。Figma同步记录不自动证明设计约束已执行。

## 材质迁移不能只核色值

同样的渐变色值用在不同长宽比例和面积的卡片上，色区、高光与空间感可能改变。仅在本次材质迁移影响这些角色时，沿原视觉目标核对应卡的色相层次、渐变覆盖、边缘和投影及受影响尺寸；布局和功能通过不能替代材质判断。局部光照需要时用有界几何适配，不能把改善质感简化为增加饱和或让暖色覆盖整页。具体角色值留项目，不把一次纠偏参数写成插件默认。若所选语言中的普通卡有弱材质，应正向定义其珠白高光、低强度冷色色阶及更淡的上下文角色，并在实际普通主卡和上下文卡上分别观看；不能把“弱化”理解成纯白平填，或用阴影代替表面材质。重点卡应维持更明显的层次。

## 在真实代表面上工作

共享呈现推广至少识别其实际消费者：目录/列表、对象详情、复杂表单等。沿项目受影响范围选择真实长值和关键正常/异常状态，并实际看展开、帮助、错误、主动作、窄屏导航及返回；没有实际状态不得伪造其业务结果。可复用未变业务证据，纯视觉调整不重放成功的业务写入。

验证范围沿项目原记录列出确切的受影响状态／视口组合，不自动展开为每种状态乘以全部视口。所声明的窄屏等组合缺少实际观察时不能签该组合通过；范围外仍未验，不以减少清单掩盖已知影响。证据绑定设计、候选、实际加载样式、对象／状态和视口；其中变化时只重新核受影响项，未变化且关联仍成立的证据继续复用，不以纯文档更新触发全站截图或业务重跑。

指标与列表由同一查询契约供给时复用原查询及数据源，避免重复读取导致口径或时点分离；不同权限或范围不能为省请求强行合并。沿原场景已有的身份、范围和来源就绪条件挂载消费者，不为布局提前越过原边界读取私有来源；不额外要求鉴权调用或先有成功样本，服务端仍执行真实授权。

旧稿对比应隔离模块和样式版本，保留相同对象与路由语义；切换不能静默丢弃未保存内容。记录当前数据是否变化，避免拿两组不同内容声称还原一致。

## 工具如何帮助

- 浏览器实际渲染与操作是必要证据；设计工具用于确定布局和组件角色。已有真实组件能直接迭代时，无需为凑流程再生成一张事后示意图。
- 截图并排/叠图须同内容、状态、视口与缩放；记录实际尺寸而非仅记录请求的模拟尺寸。共享浏览器的尺寸、缩放、会话控制应串行协调，避免截图混版。图片尺寸/摘要正确仍可能是旧绘制帧或滚动造成的固定栏错位；须观看图中对象、标题与固定元素位置，错误图弃用并重取。
- 确定性检查仅按实际风险选用已有入口，例如防止数据口径或动作条件回归。检查结构、字段或图片完整性不能判断用户任务成立；不为普通修改新建证据门禁。核工具实际消费的候选与范围，0变更或跳过不冒检查通过，但不因此重复未变化的检查。
- 需要设计对比时才保存对应图片；已有同版同态观察直接复用，不为凑图数重拍或重放业务。项目确需独立复核时沿原职责执行，不为每个补丁增加固定审阅人。

## 双结论与继续改进

先给本次用户任务的整体判断，必要时说明功能或视觉的具体缺口。实际正常消费者的正向结果尚未核到，就不能称功能可用；源代码、模拟状态或另一模式通过不补足这一点。只追本次必改问题的最小修复与结果，不逐阶段重复证明。若新稿主要阅读、信息主次、材质、首屏任务或窄屏承载不达已选目标，继续整改，不能以规范数量、截图数量或测试数结束。

采用参数先在真实场景验证，再提升为项目规范。插件保留方法，项目保留精确色值/尺寸、对象、候选和本轮通过事实。作者自验、独立视觉判断、产品方接受分别报告；不以“规范已写入”宣称已安装、其它会话已加载或后续问题不会再发生。
