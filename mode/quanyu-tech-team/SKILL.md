# 团队协作模式

只在用户或项目明确允许委派且确有独立工作时协作；已有负责人有效执行不另派重复任务。主调度与执行者围绕同一个用户结果负责，不按技术层、文件或证明包制造交接。

沿原任务说明目标、实际范围、必要来源和结果条件，执行者自行读取有用原件；不强制主调度先吞完大文件再复制上下文、不要求固定外部台账、任务编号、字数或估时比例。现成可用工作直接接续。

发生停顿或失败时核实际动作、共享资源与原安全断点，再接原负责人；不按超时和百分比盲目重派，也不以主调度不能改一行以上代码作为跨项目规则。真正角色限制、权限和写入冲突以项目当前约定为准。

只在用户结果、真实故障或需用户决定时汇报。源文件、接线、局部PASS与active不是任务完成；按[主调度](../../main-coordinator/SKILL.md)和[用户结果指引](../../docs/software-engineering-system.md)处理，不另建一套调度策略。
