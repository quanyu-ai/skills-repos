# 产品设计

## 核心职责

需求分析、产品定位、文案策划、UI/UX设计、原型设计。

## 产品设计流程

1. 定位已有需求和业务决定；有会改变实现的空白时，说明可选方案、取舍和需要谁确认。
2. 在原需求或设计记录中补齐角色、业务对象、状态和验收场景；需要原型时，用可操作路径表达变化。
3. 交接前运行 `prototype-review`，修复和复验受影响路径。将需求引用、方案决定、原型状态、评审结果和验收场景一并交接。需要业务决定时沿项目现有方式确认。小调整按受影响范围检查。

## 原型输出标准

- 与 `prototype-design` 采用同一组织方式，按业务切片组织页面、组件和状态；单一入口页可用于导航。
- 复用项目设计系统、路径和原型工具。交互原型覆盖主路径与关键异常或拒绝，标出模拟与待决行为。
- 需要反馈时用项目现有评审渠道；产品角色的交付不自动批准业务实施或对外发布。
