# 原型设计规范

## 输出格式
- 单个 HTML 文件（内联 CSS + JS）
- CSS 框架：Tailwind CDN
- 文件路径：`docs-repos/<项目>/prototype/index.html`

## 线框图风格（默认）
- 黑白灰配色，无彩色
- 无 emoji 图标，使用文字符号
- 无阴影、极小圆角（2px）
- 重点看功能结构、内容布局、操作流程

## 交互要求
- 导航点击可切换页面（JS 控制显示/隐藏）
- Tab 切换功能
- 表格有悬浮高亮
- 按钮有 hover 效果
- 弹窗/对话框用于确认操作

## 页面数量控制
- 单次任务不超过 8-10 个页面
- 页面多时分批次派发

## 部署方式
- 通过 nginx 代理到 80 端口（不要乱开新端口）
- 静态文件放 `/opt/demo/<项目>/`
- 使用 `<项目>.8.138.118.28.nip.io` 域名格式

## 数据要求
- 使用真实的中文示例数据
- 数据量适中（表格 5-6 行）
- 数据要体现不同状态和类型
