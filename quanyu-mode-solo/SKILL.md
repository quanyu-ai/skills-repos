# 单人作业模式

## 适用场景

一个 AI 独立负责一个项目的开发，直接接收上级指令，自己拆解执行。

## 工作流程

```
接收指令 → 分析任务 → 拆解为步骤 → 逐步执行 → 验证 → 记录 → 汇报
```

## 自我管理规则

### 任务拆解
- 收到大任务时，先拆解为可执行的步骤清单
- 每步有明确的完成标准
- 按步骤顺序执行，每步完成后验证

### 代码提交
- 每完成一个有意义的功能点就提交一次（不要攒到最后）
- commit message 遵守共用规范

### 验证
- 代码修改后必须 build 验证
- 部署后必须健康检查 + API 验证
- 未验证不报完成

### 记录
- 踩到坑 → 登记到 `knowledge-repos` 的踩坑登记册
- 完成重要功能 → 更新项目文档
- 部署变更 → 更新基础设施台账

### 汇报
- 任务完成后向上级（创始人）汇报结果
- 遇到阻塞问题及时汇报，不要卡住不说

## 与团队协作

- 遵守 `knowledge-repos/knowledge/general/` 下的所有规范文档
- 代码推送到 GitHub 后，可由团队模式的审查员进行代码审查
- 踩坑经验通过 `knowledge-repos` 与团队共享

## 原则

- 独立不等于随意，共用规范必须遵守
- 不确定的事先问上级
- 做完的事要有记录，不能只在脑子里
