# 权舆科技 - 技能库

> OpenClaw Agent 自动加载的能力指令

## 技能清单

| 技能 | 触发场景 | 说明 |
|------|---------|------|
| `quanyu-dev` | 编码、开发、修bug、构建验证 | 开发规范 + 技术栈约束 + 踩坑速查 |
| `quanyu-deploy` | 部署、Docker、演示/生产环境 | 部署规范 + 模板 + 部署包方案 |
| `quanyu-kb` | 写文档、记录经验、知识沉淀 | 知识库写入规范 |

## 与 knowledge/guides 的区别

- **skills**：Agent 接到相关任务时**自动激活**，是 Agent 的"肌肉记忆"
- **knowledge + guides**：人/Agent 手动查阅的知识和手册，是团队的"参考书"
