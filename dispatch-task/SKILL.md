# 按真实目标委派

仅在用户或项目允许委派且需要协作时使用。先查原负责人是否已执行，说明要解决的问题、范围、必要原件和可观察结果；让执行者直接读取相关来源，不强制复制全文、内联现有代码或填写固定台账。

不按500字、固定任务ID、绝对路径格式、commit关键词、估时倍数或特定大文件工具判断任务是否有效。合法的只读研究和代码审查不需要为了“通过派发”增加构建、推送或部署。工具确有大小限制时才选适用写入方式。

已有授权不重复申请；真实权限、文件写者及副作用边界保留。完成时核用户结果，而不是Agent报告或Tracker状态。现有check-task-desc/pre-dispatch仅确认输入可读非空，不授予委派权限或证明任务质量。项目未采用这些脚本时直接沿原协作方式执行。
