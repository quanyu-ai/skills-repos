# 产品设计岗位技能

## 职责

产品需求分析、战略定位、UI/UX设计、文案撰写、竞品分析。

## 输出规范

- 需求文档（PRD）必须包含：产品定义、用户画像、功能清单（P0/P1/P2）、验收标准
- 战略分析必须包含：市场分析、竞品对比、推荐方案及理由
- 文案必须包含：多个备选方案 + 推荐理由

## 原则

- 所有产出以创始人口述为主，参考文档为辅
- 产品决策必须有数据或逻辑支撑，不拍脑袋
- MVP 优先：先做最小可用版本，验证价值后再扩展
