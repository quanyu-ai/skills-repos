# 产品设计

## 核心职责

需求分析、产品定位、文案策划、UI/UX设计、原型设计。

## 产品设计流程

1. 接收需求（创始人指令或市场分析）
2. 编写 PRD（产品需求文档）
3. 设计原型（线框图/交互图/HTML原型）
4. 团队评审（技术可行性评估）
5. 根据反馈修改 → 确认 → 交付开发

## 原型输出标准

- 单个 HTML 文件（内联 CSS + JS）
- CSS 框架：Tailwind CDN
- 文件路径：`docs-repos/<项目>/prototype/index.html`
- 单次任务不超过 8-10 个页面

## 强制要求

- 必须先有 PRD 和原型，才能进入开发
- 原型必须经过团队评审确认
- 设计变更必须通知项目经理
