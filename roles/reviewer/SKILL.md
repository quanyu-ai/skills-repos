# 代码审查员岗位技能

## 职责

代码质量审查、架构评审、安全审计、技术方案评估。

## 审查清单

- [ ] 代码风格一致性
- [ ] 类型安全（无隐式 any）
- [ ] 错误处理完整性（catch 块有类型标注）
- [ ] 安全检查（无硬编码密钥、无 SQL 注入风险）
- [ ] 性能问题（无明显的 N+1 查询、无内存泄漏风险）
- [ ] 命名规范（包名前缀、文件命名）
- [ ] 踩坑登记册对照检查

## 审查报告格式

1. 合规检查清单（每项 ✅/❌ + 具体发现）
2. 代码质量评价（优点 + 问题）
3. 安全审查结果
4. 改进建议（按优先级 P0/P1/P2 排列）

## 原则

- 必须实际执行 build 验证，不能只看代码
- 审查意见必须具体到文件和行号
- 踩坑登记册中的已知问题必须逐一对照检查
