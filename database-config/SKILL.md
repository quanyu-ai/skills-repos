# 数据库配置与变更

围绕本次真实任务核目标环境、当前schema和数据影响，使用项目已采用的配置及受管入口。不为查询、状态核对或小修强制初始化、迁移、重建或补一套环境。

沿已有授权执行必要配置或迁移；新破坏性范围、生产权限或秘密变动按其真实边界处理。凭据不进入日志、样例或版本库，不用直接改业务数据伪造成功。

验证所改的数据约束、关系和业务读写实际成立，保事务、并发、原键幂等及未知写入对账。重复全表证明、逐行普通HTTP和无依据批量限额不是默认要求。成功已有数据不为回执重新创建。

配置文件、迁移源码或连接成功不是业务已可用；必要的实际效果由原环境负责人一次核对，后继复用。记录用户结果、实际缺口和下一动作，不强制额外状态报告、台账或逐步骤确认。
