# 数据库配置适配器

方法与授权边界见 [SKILL.md](SKILL.md)。此目录为采用该 OpenClaw 配置格式的项目提供脚本，不要求其他项目迁入，不宣称未验证的监控、数据库类型或管理能力。

- `scripts/check-db.sh`：检查所选连接，先核其实际支持参数。
- `scripts/init-db.sh`：初始化是写入操作，只在明确需要创建目标且已有授权时调用。
- `scripts/migrate-db.sh`：沿目标现有迁移与恢复机制执行必要变更。

已有连接和数据可用时，不为采用技能重建、导入或重复迁移。检查本次涉及的配置、结构和业务结果；未知写入沿原对象查清后续接，不能重跑凑成功。配置中不保存或输出真实密码。不要把脚本退出成功当作数据库业务完成。
